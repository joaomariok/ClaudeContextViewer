# context-viewer

A Claude Code mod (function-hooks plugin) that draws the context window above the prompt. `README.md` covers what it shows and its settings.

## Verify

```
claude plugin validate .
claude plugin test .
npx -y -p typescript@5.6.3 tsc -p .
```

All three pass before work counts as done. `tsconfig.json` and `.claude-plugin/types/` are generated by the engine on each load (gitignored); the API reference is `.claude-plugin/types/claude-code/index.d.ts`, so grep it for an event or prop before using one.

## Surfaces

The band draws in the terminal and the desktop app only. The VS Code extension (2.1.294) draws no mod UI at all (anthropics/claude-code#99045), so VS Code-specific code has no effect; keep the mod to `terminal` and `desktop`.

## Gotchas

- **State outlives a reload.** `$.state` keeps the value an older version of the module wrote, so every read tolerates an older `View` shape (see `usageParts`, `v.limits ?? []`).
- **Mirror `/context`, not the true trigger.** `autoCompactThreshold` is the engine's `/context` figure and ignores `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`; the owner chose to keep it as is.
- **Colours are the mod's own palette**, since `/context`'s theme colours repeat a grey across categories.
- **`next` is reserved**: a local named `next` inside a hook fails the module load.
- **`userConfig` fields are strict**: only `type`, `title`, `description`, `default`, `options`, `min`/`max`, `required`, `multiple`, `sensitive`. Keys are snake_case.

## Tests (`claude-code/testing`)

- Hooks registered on the test's `on` stand in for the engine beneath the plugin; `engine()` in `hooks/register.test.ts` is the shared stand-in. One test hook per event.
- An op event answers `{ value }` (e.g. `session.usage`); `session.measure` answers `{ changed }`.
- `find({ text: 'string' })` matches by inclusion; use `whole()` for an exact line.
- A test cannot seed `$.state`; test state-shape handling through an exported pure function.
- Per-setting tests pass values with `test(name, { options }, body)`.
